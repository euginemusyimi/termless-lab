# Termless Lab

Documentation for a Proxmox + OPNsense homelab: as-built record, incident debriefs, concept map and roadmap.

Read it as a site: enable GitHub Pages (Settings → Pages → Source: GitHub Actions) and it publishes at `https://<your-username>.github.io/<repo-name>/`.

Local preview: `pip install "mkdocs<2" mkdocs-material && mkdocs serve`

Lab only; no credentials or client data are published.
